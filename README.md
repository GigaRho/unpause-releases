# Unpause releases

Installers and update files for Unpause, the launcher for every generation of games. Nothing here is written by hand: the
release workflow in Unpause's code repository publishes every version.

- **Download Unpause**: pick the newest release on the [Releases](../../releases) page. `v0.*`, `-alpha` and `-beta` versions
  are previews.
- **Updates inside Unpause** read the `channels` release: `stable.json`, `beta.json` and `nightly.json` (one per update
  channel) and `packs.json` (data packs). Its assets are replaced on every release; do not delete it.
- **Found a problem?** Report it in [unpause-feedback](https://github.com/GigaRho/unpause-feedback).

Unpause never downloads, links to or explains how to obtain game files, BIOS files or keys.
